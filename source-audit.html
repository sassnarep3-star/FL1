How to read this

  • OFFICIAL_REGISTERED: every extracted source ID resolves to a VERIFIED Official registry entry.
  • NONOFFICIAL_REGISTERED: citations resolve, but at least one is not classified Official.
  • REGISTERED_NOT_VERIFIED: a citation exists but registry status is not VERIFIED.
  • REPOSITORY_LINK_ONLY: the only detected source is a FL1 code/artifact URL.
  • DIRECT_LINK_UNREGISTERED: an external link exists, but it is not tied to a source registry entry.
  • NO_SOURCE_LINK: the populated row has no detected citation.
  • BLANK_NO_VALUE: no nonblank value is published on the row.

These checks are syntactic and registry-based. Official sites must still be opened and the underlying fact checked before any strategy or line is trusted.
