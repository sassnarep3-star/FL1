Verification

This page is the audit trail. Every check below is a script in tools/ that can be run again by anyone, and every one of them exits non-zero on failure so it can gate a merge.

Line-by-line is literal here. tools/verify_injuries.py does not trust the normalised data file. It re-parses the raw page capture independently, rebuilds the table, and compares all 345 rows field by field in page order. A single differing character fails the build.
