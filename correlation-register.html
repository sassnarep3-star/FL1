Correlation Register — officially sourced numbers only

Requirement R27: correlations are computed only from officially sourced numbers, and every value publishes its n beside it. The rule is enforced as code: engine/corr_official.py raises unless every source id of a record is in the official set.

One value is deliberately blank. C-A4 (availability vs margin) sits at n = 1: only one week of official injury captures exists and only one game with paired inputs is settled. A correlation at n = 1 is not a small number, it is no number — so the cell is blank and the n is published, exactly as the requirement asks.
