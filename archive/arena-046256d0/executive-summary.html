5. Strategy framework (proposed, pending review)

A leaderboard-competition system for skills-based strategy selection: single bet, parlay, and player-prop combos, each required to pass validation gates (sample size, edge threshold, significance, correlation check, closing-line value, regime check, discipline check). Correlation values are computed between bet components before parlay assembly. Luck is removed by judging performance on expected value, closing-line value, and significance (z-score) with minimum-bet-count eligibility. Reward tiers go to top-performing verified strategies. [Strategies page](strategies.html)
