Depth slots as groups

A club's depth chart does not always name one starter per slot. It sometimes names two players at the same string, and it sometimes leaves a string with no name at all. Reading a chart as a flat list of “starters and backups” throws both facts away, and then quietly invents a starter the club never named. This page reads each chart as a set of slot groups and says which kind of slot each one is.
