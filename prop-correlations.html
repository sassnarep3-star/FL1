Empirical player-level correlations — closes open question Q-PROP-01

Status under the brief (B6). Correlations may be computed only from officially sourced numbers. The nflverse mirror below is third-party, so no coefficient is published on this page. The sample size n is kept for every pair so a reviewer can see what would be needed. The withheld values are listed for review on Flagged for Review (F19).

What this was. The computed research layer's correlation engine (scripts/build_correlations.py) measures team-level proxies and records Q-PROP-01: player-prop-level correlation was unmeasured because player data was unavailable to that session. This page closes that gap with the same repo rules: computed from observations, fully scripted, source-stated, and never presented as an official NFL statistic.

Data. nflverse player_stats weekly, seasons 1999–2024 (13,384 team-games; every team-game joined to a played row in data/raw/games.csv at a 100% join rate after canonicalizing historical abbreviations SD→LAC, STL/OAK/LA→LAR, OAK→LV). Mirror: Beexly/Sports (data/nflverse/player_stats_weekly_archive.parquet, commit 2026-11-07). The mirror is QA-gated before use (schema, coverage, 100% score join, distribution sanity) — any gate failure aborts publication.

How to read it. For two independent legs the parlay hit probability is P(A)·P(B). Positive dependence raises the true joint probability above that product; the table's lift column is exactly the multiplier P(A and B) / (P(A)·P(B)) at the listed thresholds. A same-game parlay built from positively dependent legs priced as independent is overpriced in your favor; a correlation cap (see validation gates) still applies.

Reading notes and limits

  • Aggregates are position-group totals per team-game (all WRs, all RBs+FBs, all TEs, sum of QB passing). No ex-post selection (e.g., "leading receiver" conditioning), which would bias correlations upward.
  • QB↔WR aggregate correlation (r ≈ 0.79, n = 5,246) is a same-offense volume relationship, not a guarantee for any single named pair; use it as a prior, then gate on actual n.
  • RB rushing ↔ RB receiving is essentially uncorrelated (r ≈ −0.07): workload in one phase does not determine the other — useful for building correlated RB props deliberately rather than assuming dependence.
  • Binary lifts are threshold-specific: re-derive for different thresholds before pricing.
  • Estimates were computed from nflverse-derived data via a third-party mirror. Under brief B6 they are withheld and are not verified league facts. n is published; values are not.
