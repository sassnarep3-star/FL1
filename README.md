# FL1

NFL line origination, signal research, and decision-support site.

## Live site

Published on GitHub Pages: **https://sassnarep3-star.github.io/FL1/**

## What's here

- **Dashboard** (`index.html`) — landing page with verified findings summary.
- **Executive Summary** (`executive-summary.html`) — key details and current status.
- **Decisions & Questions** (`questions.html`) — decision-gate questions with required information and answers/sources.
- **Suggestions** (`suggestions.html`) — reviewable improvement and information-discovery suggestions (nothing implemented without review).
- **Strategies & Leaderboard** (`strategies.html`) — single bet / parlay / player-prop framework, validation gates, correlation methodology, luck removal, leaderboard rewards.
- **Injury Report** (`injury-report.html`) — full Week 10 official injury report plus starter-level deficiency watchlist.
- **Standings** (`standings.html`) — verified 32-team table with computed PPG/PPA.
- **Lines & Market** (`lines.html`) — Week 10 slate; line values left blank and flagged until verified on an official sportsbook.
- **Flagged for Review** (`flagged-review.html`) — all irregularities and unverified items with source links.
- **Sources** (`sources.html`) — all official sources used.

## Data & verification

- `data/` holds the verified source datasets and the line-by-line verification log.
- Every table row links to an official source. Values that cannot be confirmed from an
  official source are left blank and flagged — never inferred.
- `COORDINATION.md` is the shared task board for parallel sessions.
