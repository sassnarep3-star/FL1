Removal of luck

A leaderboard ranks something. Before it ranks anything, this page publishes the size of the thing it will be ranking against: how much of a result chance alone could produce, and how many decisions it would take before chance stopped being a plausible explanation.

The home-team hit rate over 137 official games is 48.9%. Its 95% interval is 40.7% to 57.2%, which contains 50%. On this sample, backing the home team every time is indistinguishable from a coin flip — which is exactly the point: a season is not long enough for a small edge to become visible.

What this means for the leaderboard

Rank on a proper score, with the sample size published beside it

Ranking the best of 6 strategies without adjusting the threshold is how a lucky run gets mistaken for a method. With the Bonferroni-adjusted threshold the 5pp-edge sample rises from 785 to 1211 decisions.

The intra-cluster correlation between legs of the same game is NOT measured in this repository — no joint-outcome source has been captured. The grid below is therefore a sensitivity, not an estimate: it shows how fast the required sample grows if legs inside one game are correlated at all.

Companion signal-level decomposition (per-strategy p-values, certifiable edges, sample floors) lives on Decision Readiness → Luck.
