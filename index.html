A decision-support dashboard for originating NFL betting lines. All data below is pulled from verified, official sources where available. Any value that cannot be confirmed from an official source is left blank and flagged unverified — nothing is inferred or filled in.

How to use this site

Decision-making: Review the Executive Summary for the recommended path, then inspect the category tables (Injuries, Depth & Deficiencies, Standings, Strategies). Every table row carries a link to its official source, or is marked unverified.

Suggestions: Use the Flagged for Review page to review unverified items and irregularities before implementing any changes. No change should be implemented until a suggestion has been reviewed and a path chosen.
