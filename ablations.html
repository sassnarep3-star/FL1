Injury / personnel ablations — not fixed penalties

The brief rejects “subtract a fixed number of points for a missing starter”. The alternative implemented here: run the same model twice — once without and once with the availability features — on chronological holdouts, and report the difference with uncertainty. The feature’s fitted coefficients are published with their own intervals, so the effect of a non-primary starting QB is an estimate, never an assumed constant.

Design (frozen before the holdout was scored)

Identical model shapes differing only in the availability features:

  • WITHOUT: intercept + prior-3-game scoring-margin difference (a naive strength proxy).
  • WITH: the same, plus four 0/1 indicators — each side’s QB-deficiency class (“2nd different starter”, “3rd-or-later”) from data/depth_deficiency.csv, derived from the recorded starting QB identity.
  • Splits (chronological, never random): train 1999–2019 · validation 2020–2021 (stability reading only — nothing is chosen on it) · holdout 2022–2025, scored exactly once after freezing · 2026 excluded entirely (season in progress).
  • Difference statistic: MAE(with) − MAE(without) on the holdout, paired by game; 95% CI by paired bootstrap over per-game absolute errors (seed 20261116, 4,000 resamples).
  • Why not a fixed penalty: a fixed penalty asserts the adjustment’s size with no uncertainty and no test. Here the size is fitted from training data and published with an interval, and whether the feature helps at all is decided on the holdout.

Provenance and limits

  • Inputs: data/raw/games.csv (nflverse feed, source S47, third-party snapshot — flag F62) and data/depth_deficiency.csv (QB-deficiency classes derived from the same feed’s recorded starters by scripts/build_availability.py).
  • Not official: no output on this page is an official NFL publication. The feature measures who STARTED (recorded game participation), not injury designations; the official-only correlation register is separate and unaffected.
  • Scope: the feature set is deliberately small (QB identity classes). The full 2nd/3rd/4th-string deficiency feature needs the depth-order source decision (Q04/Q05) before it can join the ablation — this page is the harness it will slot into.
  • Engine: engine/ablation.py (stdlib-only least squares + seeded bootstrap); unit-tested in tests/test_gsession.py.
