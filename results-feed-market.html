Verified results feed

Backtests and ROI are impossible without a result nobody can argue with. This feed admits a game with an explicit verification status, and settlement is refused for any game whose status is not earned. A result taken from the same file as the price is not verification: it is a tautology, so the status column says which of the two it is.
