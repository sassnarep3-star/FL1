Line Origination

How a line would be produced here, and precisely where the production stops because a source is missing. This is a specification, not a forecast.

There is no line on this page. Not because the method is unclear, but because a fair-value number requires two things this repository does not have: a fitted model and a benchmark price to compare against. Publishing a number without those would be an invention, and an invented number is worse than a blank one because it looks finished. See F08.

The four stages

  1. Input — only officially sourced fields enter the model. Each input is registered with the source that supplies it and the date it was captured. An input without a source is not an input.
  2. Estimate — a marginal strength estimate per club, converted to an expected margin and an expected total. The first, mandatory estimator is the naive baseline: season points differential per game.
  3. Price — convert the expected margin into a probability distribution over outcomes. Report the fair-value probability and an explicit uncertainty band. Report no price if no market price exists to compare with.
  4. Seal — hash the full prediction set and publish the hash before kickoff. The seal is what makes the record auditable rather than anecdotal.

Why uncertainty is a required output, not a disclaimer

A single number implies a precision the data does not have. With eight or nine games played per club, the standard error on a scoring-margin estimate is large enough that two plausible models can differ by more than the gap between them and the market. Reporting a band makes that visible; reporting a point estimate hides it. The correct response to wide uncertainty is a smaller stake or no position, not a tighter number.

Origination order (requirement R23)

The order is mandated and fixed before results: the side first, then the total, then the moneyline. The moneyline is priced last because it is derived from the same margin distribution the side model produces — one model behind the markets, so the markets cannot contradict each other. This supersedes the earlier “totals-first” design note; the change is logged as F27 rather than made silently.
