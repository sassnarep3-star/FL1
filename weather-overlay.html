The stadium roof/surface overlay combines the official Game Book venue line with the NWS forecast grid resolved for each Week 11 venue. Roof and surface are Game Book facts (the NFL does not publish them elsewhere); the NWS supplies the forecast grid for each venue’s official coordinates.

Scope note: the NWS grid identifiers (office/gridX/gridY) were resolved and verified this session. The hourly forecast VALUES (temperature, precipitation probability, wind) were read live but are not retained in this canonical capture, so they are left blank rather than inferred. Roof/surface is published only where an official Game Book reading exists (MetLife Stadium and AT&T Stadium, from the Week 10 Game Books); every other Week 11 venue has no game-day Game Book yet and is left blank. A refresh fills the hourly columns from the live NWS response.
