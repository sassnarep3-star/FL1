# Row-level source audit

`source-audit.html` and `data/source_row_audit.tsv` are generated by `tools/source_audit.py` after the
other root-site pages have been rendered by `tools/site.py`.

The audit is deliberately conservative. It scans each rendered table body row and extracts the source
IDs and links present in that row. A citation is classified `OFFICIAL_REGISTERED` only when every
extracted source ID resolves to a `data/sources.tsv` entry whose tier begins with `Official` and whose
status is `VERIFIED`. Third-party sources, partial or unverified entries, repository-generator links,
unregistered direct links, rows with no detected citation, and blank-value rows remain separate
classes. The audit does not fetch links, verify the truth of a table value, or turn a third-party source
into an official one.

A link to `tools/site.py` documents the rendering implementation; it does **not** verify the NFL facts
rendered in a row. The page therefore calls such a citation `REPOSITORY_LINK_ONLY`. This addresses a
provenance weakness in the existing generic source-chip fallback without rewriting historical data.

## Rebuild and test

```sh
python3 tools/site.py
python3 tools/checklinks.py
python3 tools/checkrows.py
python3 -m unittest tests.test_source_audit -v
```

`data/source_row_audit.tsv` has one entry for each table body row scanned, with page/table/row
coordinates, classification, source IDs, registry URLs, and a short rendered-text excerpt. It is an audit
index for manual review, not a substitute for opening and checking the official source page.
