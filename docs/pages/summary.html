1. The short version

The programme was asked to originate NFL lines, rank strategies on a rewarded leaderboard, track injuries and depth deficiencies, verify everything against official sources, and publish it as a live site. At this branch's base commit the repository was one 6-byte file; main is now a published site built by six merged pull requests. This branch delivers the analytical and governance layer the published site does not yet have: a sourced register set, a tested engine, a compliance veto, and a generated sub-site whose build fails if a row loses its source. Line-origination *results* are still not delivered, because they depend on a publishing decision about third-party data — a much cheaper question now than the licence purchase it replaced, because a sibling session has already committed closing-line history to data/raw/.

Overfitting dressed as an edgeWith 14 named candidate signals and a small sample, something will look good by construction. It is the default outcome, not a tail risk.G-5 multiple-comparison control over every strategy tried (including retired ones), G-6 deflator, G-9 walk-forward-only, and rank on a lower confidence bound.
Using information we should not useInjury and lineup information is exactly where the league's integrity program is most active: personnel may not share non-public information, betting patterns are monitored, and each club has an assigned integrity representative.Compliance gate G-12 refuses prohibited market classes; the input allowlist is the source register, and CI fails on any input not in it (Q-23).
Betting on markets the league prohibitsThe brief's injury-tracking requirement naturally points at injury-adjacent markets, which the league asks operators not to offer at all.Injury data is permitted as an *input* to spread/total/prop pricing and banned as a *subject*; engine/compliance.py enforces it and refuses unknown markets rather than allowing them.
Infrastructure that quietly stopsThere is no host yet, so 'no manual input' is a design property of the code, not a live capability. A stale dashboard is worse than an absent one.Every page prints the data's as-of date; the collector is specified with a schema-drift alert and a publish-to-price stopwatch (Q-17, GAP-18).
Correlation assumed rather than measuredA parlay's true win probability depends on dependence between legs; assuming independence overstates it, and the error compounds per leg.The parlay path refuses a joint probability it has not measured, and prints a sensitivity-to-rho check that refuses any bet whose sign flips under a plausible correlation error.
Legal exposure from a paid-entry, partly-luck contestEntry fee, chance and prize is the regulated shape; the league's own posture on prediction markets and daily fantasy shows how closely the neighbourhood is policed.Non-cash rewards by default; the cash question is escalated to counsel and left explicitly open (D-3).
Gambler's fallacy and hot-hand narratives entering the modelThe literature exists precisely because bettors and bookmakers both misread streaks; a 'due for a bounce-back' feature is a coin toss wearing a tie.Every streak-style signal (SIG-01, SIG-02, SIG-03) must survive the same gates as everything else, and none is quoted as established fact — they are labelled hypotheses with a source at abstract level only.

6. What this project refuses to claim

6. What this project refuses to claim
RefusedBecause
That any strategy is profitable, close to profitable, or likely to be profitableNo bet log was ever run against real prices. The demo output uses synthetic logs specifically so that the *evaluator* can be checked; it is labelled on every page where it appears.
Any coefficient in the origination modelEvery parameter is an argument to be fitted from data, not a constant. Publishing a number would create exactly the untraceable input the brief forbids.
Any designation-to-probability mappingThe league's definitions are qualitative (Questionable means uncertain). The folklore percentages have no official basis, and hard-coding them would make the injury model look calibrated when it is not.
Any Nevada or per-market hold percentageThe regulator documents exist and are the right source; we did not open them at page level, so the number is a gap rather than a figure.
That the injury sample is a picture of Week 10It is one chunk of an eight-chunk page. The rows we hold are verbatim and complete for what they cover; the coverage is partial and says so.
That 'reachable' equals 'verified'A sibling page labels a reachable URL as verified content. Reachability is a weaker tier, and this project keeps the tiers separate: FETCHED, INDEX-MEANS, LINKED, UNREACHABLE.

Verification rule. Every factual row links to an official source — the league (nfl.com and its subdomains), a state gaming regulator, or a peer-reviewed publication. A value that could not be confirmed from an official source is left blank and flagged rather than estimated. Source verification levels: FETCHED = page opened and read · INDEX-MEANS = seen through a search index of the official document only · LINKED = reached from an official page, not opened · UNREACHABLE = tried and failed.
