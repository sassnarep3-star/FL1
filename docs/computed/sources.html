Sources

Official, open-data and secondary sources, each with the exact use and verification status.

Every source used anywhere in this repository. The tier says how much weight it can carry: an Official source can establish a fact; Open data is reproducible and pinned by hash; Secondary is context only and is never the origin of a computed number.
