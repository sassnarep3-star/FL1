The headline finding: nothing beat the market. Sixteen pre-registered strategy variants were tested on 5,336 games. Zero passed all seven validation gates. The best raw candidate (WIND15_UNDER) earned 7.2% ROI over 425 bets with p = 0.0628, which fails the significance gate and the multiple-testing gate. A control strategy that bets every home team returned -5.2%, which is what the house vig should cost. This result is published as the finding, not hidden.
Where this fits. The main site at the repository root holds the verified data register, the open-questions board and the suggestion register maintained by the integrating session. This layer is the computed half: it takes open, pinned datasets and tries to falsify a strategy against them. Read the main site for what is known; read this one for what survived testing.

What was asked for, and what is real

Every requirement from the brief is tracked in Requirements with a status and the file that evidences it. Four are not fully met, and the site says so on the page where the gap lives rather than burying it:

  • Own lines — a reproducible causal Elo-to-spread model exists and is priced, but its disagreement with the close sits inside the market's own error band. Not yet an independent line.
  • Player prop combos — no prop line/outcome dataset was obtainable. Team-level same-game correlation is measured; props are not.
  • 2nd/3rd/4th string — no reachable source publishes depth order. Only QB changes are attributable, and they are labelled “different starter”, never a claimed depth slot.
  • Removing luck — luck is bounded by gates, not eliminated. Every threshold used is listed on Methods, and the ones that are my choice rather than yours are open questions.

Start here

The fastest path through the site for a decision-maker: Findings → Suggestions → Open questions → Flagged for review. The first three give you the picture and the decision paths; the last is the list of things that could not be verified and must not be trusted yet.

How to read a number on this site

Every table that contains a computed value names the source file it came from, and every source file names the URL and SHA-256 it was built from (data/raw/MANIFEST.json). ROI is always against the closing price, because that is the only price available for the full sample — see FLAG-08. Pushes are removed from both the numerator and the denominator. A blank cell means the value could not be sourced; it is listed on Flagged for review, never filled in.
