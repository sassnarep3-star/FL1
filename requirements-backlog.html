How to read this page

Four kinds of row

done — the artefact exists in this repository and is re-runnable. partial — started, but the blocking gate is still open. blocked — waiting on an official source that does not exist yet in any form we can cite. not-started — nothing depends on it being blocked; it simply has not been built. rejected rows are kept with their reason, because a shortcut nobody records gets re-proposed next week.

Rows R01–R28 come from the register built by earlier sessions (data/requirements.json); rows R29–R87 were added by this session from the brief lines that register did not yet track (data/requirements_backlog.csv).
